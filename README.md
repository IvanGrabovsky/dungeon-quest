# ⚔️ Dungeon Loot Quest: Скарби Підземелля

> **Практичне завдання з JavaScript:** Умовні конструкції (`if/else`, `switch`), логічні оператори (`&&`, `||`, `!`), оператори порівняння та пріоритети обчислень.

---

## 🐉 Сюжет місії

Ти опиняєшся у стародавньому підземеллі забутого замку. Попереду — охоронці дракона, скрині з магічними пастками та важкі бої.
Щоб твій персонаж вижив і знайшов легендарний артефакт, тобі потрібно запрограмувати бойовий рушій гри:

1. Написати безпечний алгоритм відкриття скринь з пастками.
2. Розраховувати бойову шкоду залежно від зброї та критичного удару.
3. Відстежувати життєві показники та статус героя під час поєдинку.

---

## 📋 Завдання

Відкрийте файл [`src/quest.js`](src/quest.js) та реалізуйте три функції:

### 1. `canOpenChest(hasKey, lockpickLevel, isTrapDisarmed)`
- Скриню **заборонено** відкривати (`false`), якщо пастка не знешкоджена (`isTrapDisarmed === false`), інакше герой загине від отрути!
- Якщо пастка знешкоджена, скриню можна відкрити (`true`), якщо:
  - у героя є ключ (`hasKey === true`) **АБО**
  - рівень злому відмичками не менше 60 (`lockpickLevel >= 60`).
- В інших випадках повертає `false`.

### 2. `calculateDamage(attackPower, weaponClass, isCrit)`
- Базова атака залежить від класу зброї:
  - `'sword'` -> `attackPower * 1.0`
  - `'bow'` -> `attackPower * 1.2`
  - `'staff'` -> `attackPower * 1.5`
  - будь-яка інша зброя -> `attackPower * 0.5`
- Якщо спрацював критичний удар (`isCrit === true`), розрахована шкода подвоюється (`* 2`).
- Результат поверніть цілим числом, округливши через `Math.round()`.

### 3. `getHeroStatus(currentHp, maxHp)`
- Якщо `maxHp <= 0` або `currentHp <= 0` — статус `'Defeated'`.
- Рахуємо відсоток: `(currentHp / maxHp) * 100`.
- Менше 25% — `'Critical'`.
- Від 25% до 75% включно — `'Wounded'`.
- Більше 75% — `'Healthy'`.

## 🛠️ Як працювати з проєктом

### 1. Встановлення залежностей
```bash
npm install
```

### 2. Запуск тестів
```bash
npm test
```
*Для автоматичного перезапуску при зміні файлу:*
```bash
npm run test:watch
```

1. Зробіть **Fork** цього репозиторію у свій акаунт GitHub.
2. Склонуйте ваш форк на комп'ютер:
   ```bash

   ```
3. Виконайте завдання у файлі `src/quest.js`.
4. Перевірте проходження всіх тестів локально (`npm test`).
5. Збережіть зміни та завантажте на GitHub:
   ```bash
   git add .
   git commit -m "feat: complete dungeon quest combat logic"
   git push origin main
   ```
6. Перейдіть на GitHub у вкладку **Actions** вашого репозиторію — там автоматично запуститься тестування та загориться зелена галочка ✅!
